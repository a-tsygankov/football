Where it lands: the settlements are written into the game_recorded event payload as an optional wagers field, and the live bets rows are deleted. The event log is the only durable record — there is no balance column to drift.

Edge cases: nobody backed the result → every stake is refunded (payout = stake, everyone nets 0). Game interrupted → bets are discarded with no settlement. Game later voided by an admin → it simply drops out of the derived standings.
