Game Night wagering — the whole loop

One pari-mutuel pool per game. Chips are virtual, per-night, and derived from the event log — no balances stored anywhere.

1
A live game starts

Ann (home) vs Bob (away), with Cyd in the night's pool but sitting out. The Bets panel appears under the team cards with an empty book.

POST /game-nights/:id/games → bets: []
2
Anyone in the pool stakes chips

Pick who's betting, pick an outcome, enter a stake (1–1,000,000 whole chips). One bet per gamer per game — betting again replaces. Participants may back only their own side; draw is blocked for them.

POST …/bets → 201 book · 400 outcome_not_allowed
3
The book locks

Manually with the Lock button — or automatically the moment someone opens the TV photo capture, because a result is about to be visible. Locking is idempotent; late bets get a 409.

POST …/bets/lock → betsLockedAt · late bet → 409 bets_locked
4
The result is recorded

The worker settles the pool: backers of the actual result split the whole pot pro‑rata to their stake. If nobody backed the result, every stake is refunded. The split is written into the game_recorded event as wagers, then the live rows are deleted.

the event payload is the durable record
5
“Chips tonight” updates

Standings are recomputed from the night's game_recorded events on every read — interrupted games discard their bets, voided games drop out automatically. Then the next game opens a fresh book.

GET …/chips → positions + lastGameDeltas
